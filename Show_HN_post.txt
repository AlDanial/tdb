I'm a vim/command line guy and loved using pudb
(https://pypi.org/project/pudb/) as I was learning Python.
Gradually my code became more complex and pudb wasn't
keeping up; event loops and the threading and multiprocessing
modules were problematic.

TL;DR:  I used Claude Code to write the TUI debugger of my
dreams:  https://pypi.org/project/textual-debugger/
It's built with textual and debugpy so can do all the
things possible you'd would expect with the Debug Adapter
Protocol (remote attach, thread/process inspection).

And then some!

I added a JSON-RPC interface so the debugger can be controlled
by external tools (eg an AI agent).  I also added the capability
to run the debug target in a separate terminal which is handy
for debugging applications that make demands on the terminal
(like curses / rich / textual apps).
